# Evolutionary Van Gogh Project

A project for exploring evolutionary algorithm variants applied to image approximation and optimization.

## Overview

This project tackles the **Evolutionary Van Gogh** assignment: imitating an existing painting
(Vincent van Gogh's *"Wheat Field with Cypresses"*) using a Genetic Algorithm. Images are
"drawn" with **Voronoi diagrams**, where each individual's genotype encodes a set of points,
each described by a position `(x, y)` and a color `(r, g, b)`. Every pixel takes the color of
its nearest point, partitioning the image into colored cells.

Fitness is measured by comparing the imitation against the reference image pixel-by-pixel
(via `imgcompare`, lower is better). Starting from a baseline GA (one-point crossover, random
initialization, P+O tournament selection), this repository extends the implementation with a
range of selection strategies, gray-box optimization variants, and Voronoi-aware operators, and
benchmarks their impact on optimization performance.

Experiments were run with a point budget of 50/100 points and a generation budget of 500,
following the assignment's recommended setup.

## Setup

To run this code, install the required packages from `requirements.txt`:

```bash
pip install -r requirements.txt
```

To work with the notebooks, start Jupyter in this directory:

```bash
jupyter notebook
```

## Contents

The main analysis entry points are the Jupyter notebooks below, grouped by the variant they
investigate.

### Selection methods
- `analysis_ssga.ipynb` — Steady-state genetic algorithm (SSGA) variant.
- `analysis_sus_select.ipynb` — Stochastic universal sampling (SUS) selection.
- `analysis_tournmament_select.ipynb` — Tournament selection experiments (varying tournament size).
- `analysis_trunc.ipynb` — Truncation selection and related settings.

### Gray-box optimization variants
- `analysis_greybox_edgebased.ipynb` — Gray-box edge-based evolutionary variant.
- `analysis_greybox_regionbased.ipynb` — Gray-box region-based evolutionary variant.

### Voronoi-aware operators
- `analysis_voronoi-preserving.ipynb` — Voronoi-preserving crossover and mutation variants.

## Reproducing experiments

1. Install dependencies (see **Setup**).
2. Open the notebook for the variant you want to reproduce.
3. Run the cells top to bottom. Each notebook plots optimization progress over time and displays
   intermediate imitations.
4. Generated CSVs and figures are written to the corresponding `csv_files_*/`, `results_*/`, and
   `img/` directories for review and plotting.

> **Note:** a single run can take roughly 3–5 minutes, so plan accordingly when running multiple
> repetitions or sweeping hyperparameters (e.g. population size, mutation strength).
